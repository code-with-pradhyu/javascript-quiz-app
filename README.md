# 🧠 JavaScript Quiz App

A responsive and interactive **JavaScript Quiz App** built using **HTML, CSS, and Vanilla JavaScript**.

This project was created to practice JavaScript concepts such as arrays, objects, functions, DOM manipulation, event handling, dynamic rendering, and application state management.

## 🚀 Live Demo

🔗 https://code-with-pradhyu.github.io/javascript-quiz-app/

## 📸 Features

- 🧠 Multiple JavaScript-based quiz questions
- 🎯 Dynamic question and option rendering
- ✅ Highlights the correct answer
- ❌ Highlights an incorrect selected answer
- 📊 Real-time score tracking
- ➕ Correct answer: **+2 points**
- ➖ Wrong answer: **-0.50 points**
- 🛑 Prevents changing the answer after submission
- ⏭️ Next question navigation
- 🏆 Final score/result screen
- 🔄 Restart quiz functionality
- 📱 Responsive and clean UI

## 🛠️ Technologies Used

- **CSS3** — Styling and responsive layout
